# Bound workflow invocation

The calling packet provides `reviewContext` with the issue URL, fixed point, committed candidate head/base, approved plan and checks fingerprints, and repository Markdown source candidates. Read the issue and its acceptance criteria using the host's tracker access. Read the approved `planPath` and `checksPath` in the packet. Inspect the candidate diff at the exact supplied head and fixed point. If a source, candidate, or tool is unavailable, report `incomplete`; never turn a skipped axis into a pass.

For a bound `authorReview` invocation, issue one `skill-delegate` request with exactly two required independent children, named `standards` and `spec`. Each child receives the diff command, commit list, its own source list, and the relevant brief from this skill's Process section. Use the current L3 tier for both; the workflow supplies the actual model and gives each child a separate native context. Run them concurrently within the workflow's agent budget. Read their actual completed results with `skill-continue`, then aggregate without cross-axis reranking. Do not create hidden sub-agents outside `skill-delegate`.

The final raw output must contain separate Standards and Spec results, each with source citations, findings, and an explicit pass/changes_required/incomplete conclusion. Finish with `skill-finish` using the host's terminal receipt and the raw output as evidence. Use `pass` only after both required children completed and no blocking finding remains. `changes_required` is blocking; `incomplete` and `skipped` cannot satisfy the workflow gate. The outer actor cites this invocation once in `data.skillInvocationIds`. When this review was requested inside implement, its child actor returns `completed` with that invocation ID, and the implementation parent reads it through `skill-continue` before finishing.

The workflow owns candidate/source matching, role observations, budgets, and receipt validation. This skill owns the two review axes, independent prompts, finding judgement, and report format.
